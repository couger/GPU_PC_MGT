# 公开前问题修复与验证

本轮针对早期版本的安全、可靠性和发布材料整理。项目仍为实验性，不承诺全部设备或运行环境安全可用。

| 问题 | 修复与覆盖 |
| --- | --- |
| SSH 参数/脚本注入 | 统一主机、用户、路径、端口校验与 Windows 参数引用；编码远端脚本，严格主机验证；security-test |
| 失败或旧采样显示正常 | 协议 v3 成功状态、受控错误、源时间、单调年龄与样本 ID；失败/过期拒绝，重复样本不刷新年龄；security-test / probe-boundary-test |
| 慢速连接阻塞 | 八个有界并发、三秒总期限、严格读取长度；正常客户端与慢速连接并行集成测试 |
| 网络明文凭据 | TLS 1.2、固定 SHA-256 指纹、有效期检查、默认回环及禁止自动降级；错误/过期证书及明文请求测试 |
| 令牌明文落盘 | 当前用户 DPAPI、旧字段迁移、最终及临时文件限制性 ACL；迁移/ACL 测试 |
| 诊断与剪贴板风险 | 不记录完整命令/原始响应；复制秘密提示及分享限制；日志/故障回归 |
| 辅助工具命令行密码 | 改为隐藏输入；旧明文启动/迁移入口停用，统一安全安装 |
| 安装、升级、卸载 | 管理员安装系统采集和有限权限用户托盘，受保护 bin、精确防火墙、一次回滚副本；语法及无变更规划测试 |
| 网页兼容源码边界 | 动态驱动器文本转义，静态服务仅两个允许文件，拒绝目录穿越/逃逸；web-security-test |
| 发布材料与流程 | 所有者选择 MIT，实验性 README、贡献/安全/变更/操作文档、问题模板、固定 Action 版本和全历史扫描 |

Windows 本地完整回归和协议/TLS 边界测试可由 tools/run-tests.ps1 重现；CI 的 SkipDesktop 不代替真实桌面验收。源码检查通过不能保证未来配置、截图、日志或打包附件没有隐私；每次发布仍检查最终包和完整历史。

安装器目前验证语法、WhatIf 无变更、非法地址及拒绝接管其他任务。**没有据此宣称已在每台实际设备完成管理员安装、升级、断电回滚或卸载验收。** 操作需要先在可恢复环境验证，并重新复制 TLS 凭据。

开源许可和技术检查不证明第三方内容所有权；后续贡献需遵循 CONTRIBUTING.md。是否公开仓库是独立操作，不由构建或测试脚本自动执行。
